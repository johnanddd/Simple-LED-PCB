# Simple LED PCB
A small first PCB I made.

This was my first custom PCB project, designed in KiCad and manufactured as a physical board.

The goal was to learn the complete PCB design workflow from schematic capture and component placement through routing, fabrication, soldering, and hardware testing.

## Final Result

The completed board was assembled and tested using an external battery supply.

![Powered PCB](images/powered_pcb.jpeg)

## Circuit

The circuit is a simple LED indicator powered through a 330 Ω current-limiting resistor.

After completing the PCB design and design rule checks, I generated the manufacturing files and had the board fabricated.

The resistor, LED, and power wires were soldered onto the fabricated PCB.

## Testing

The finished board was connected to a battery pack and successfully powered the LED.

![Powered PCB](images/powered_pcb.jpeg)

## What I Learned

- Schematic capture in KiCad
- Component and footprint selection
- PCB placement and routing
- Design rule checking
- Through-hole PCB design
- Gerber generation
- PCB fabrication workflow
- Through-hole soldering
- Basic hardware testing and debugging
